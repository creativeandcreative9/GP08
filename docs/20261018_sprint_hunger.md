# 連続走行の加速と空腹度

2026年10月18日の追加要望「走り続けて10秒で2倍、20秒で3倍」「空腹のパラメータ」に対応する。

## 操作と加速

- PC は移動キーと Shift、スマホは「走る」をオンにして移動スティックを操作する。
- 走り始めは従来の走行速度40単位/秒。連続して実際に走るほど滑らかに加速し、10秒で80、20秒で120単位/秒が目標速度になる。上限は3倍。
- 歩行は従来の17.5単位/秒。歩く・止まる・壁に阻まれる・会話やメニューを開く・座る・室内への出入り・タブを離れると連続走行の加速をリセットする。
- 走行中は上部に倍率を表示する。高速走行でも壁を飛び越えないよう、衝突判定を細かく区切る。
- 加速時間はセーブしない。再開直後は通常の走行から始める。

## 空腹と飲食

空腹度は **0で満腹、100で空腹**。上部に数値と状態を常時表示し、押すと持ち物を開く。表示は整数に四捨五入し、表示値が30未満は「満腹」、30〜69は「小腹」、70以上は「空腹」。保存と計算には小数を保持する。空腹は食事や寄り道の目安で、移動速度を下げたりゲームオーバーにしたりしない。

時間が進んでいる間だけ、実時間1秒につき `(1 + 走行倍率) / 12` 増える。歩行・停止・着席中の走行倍率は0として扱う。通常は満腹から20実分、3倍速を維持した走行では5実分で100となる。ゲーム内では1実秒が1分なので、通常はゲーム内1時間に5増える。

会話・手帳・地図などのメニュー、景色の鑑賞中、非表示タブでは時計と空腹を止める。タブへ戻った最初のフレームでは経過時間を取り込まず、閉じていた間の空腹も計算しない。

| 飲食物 | 空腹度の回復量 |
| --- | ---: |
| おにぎり | 45 |
| 三色だんご | 25 |
| 持ち帰りコーヒー | 5 |
| 緑茶 | 3 |

購入しただけでは回復せず、持ち物から食べる・飲むと回復する。回復後の下限は0。満腹でも以前と同じく飲食でき、街歩きの目標やおやつの思い出を進められる。

自宅に入るとヒントまたは持ち物から無料の軽食を食べられる。空腹度が0に戻り、所持金・持ち物・時刻は変わらない。自宅の外では持ち物から帰宅の案内を選べる。自宅で眠って朝を迎えると無料の朝食で0になる。所持金0円や夜でも回復できる。

## 保存

`gp08.life.v1` の形式3を維持し、`Progress.hunger` に小数を含む0〜100を保存する。自動保存と記録1〜3に含まれる。旧形式1〜3で空腹度がない場合は0を補い、進行や所持金は保持する。範囲外、文字列、nullなど不正な空腹度を含む保存は受け付けない。
