# スマホ実機での確認

[GP08をブラウザで開く](https://creativeandcreative9.github.io/GP08/)。スマホの通常のSafari／Chromeで、現在公開されている版を開く。私有モデル・参考画像やPCでのZIP配信は不要。確認対象の版は、設定からコピーする計測結果内のビルド名で区別する。

連続走行の加速と空腹・食事を追加した `index-CJkbrCW7.js` を公開URLへ反映済み。公開HTML・JS・CSSが検証済みビルドと一致することを確認した。以下の追加機能も、この版で確認できる。スマホ実機の操作感と性能は未測定であり、この手順を実施した結果から評価する。

別の配信先を使う場合は公開用dist/またはZIPの展開内容を通常の静的サイトへ置く。ファイルを直接開く方法には対応しない。PCを利用できる場合は展開フォルダーで `python3 -m http.server 8080 --bind 0.0.0.0` を実行し、同じWi-FiのスマホからそのPCのLANアドレスの8080番を開く。配信するのは展開した公開ファイルだけとし、リポジトリや私有アセットの親フォルダーを指定しない。

## 動作の計測

1. スマホの通常のSafari／Chromeで開き、設定の「画質：自動調整で再開」を選ぶ。タッチ端末は軽量画質から始まる。
2. 駅前から商店街、公園へ1分ほど歩く。読み込み直後の準備を終え、縦画面・横画面で操作できることを確かめる。
3. 設定の「動作を30秒測る」を押し、準備表示のあと、同じ道をいつもどおり歩く。メニューや別アプリを開いている間は計測が止まる。
4. 完了メッセージが出たら、設定の「動作の確認」で平均FPS・中央値・遅い側のフレーム時間を確認し、「結果をコピー」を押す。コピーできない場合は結果欄を長押ししてコピーする。
5. 機種、OS、ブラウザと、歩いた場所・気になったカクつきを添えて結果を共有する。向きや画質を変えて再計測する場合は、先に結果を控える。再読み込みで計測結果は消える。ゲームのセーブは通常どおり保持される。

結果には測定日時・ビルド名・ブラウザ・フレーム数と時間・測定前後の画質／描画サイズ／解像度倍率・画面サイズを含む。公開更新の前後で結果を比べるときは、ビルド名も控える。ゲームの所持金・座標・セーブ内容・アクセス先URLは含めず、自動送信しない。遅いフレームは省かず、平均FPSは全測定時間から求める。これは歩いた範囲の計測であり、全端末・全場面の性能保証にはしない。

## 連続走行と空腹の確認

1. 「走る」をオンにし、障害物のない道で移動スティックを倒し続ける。上部の倍率が徐々に増え、10秒で約×2.0、20秒で×3.0になる。3倍が上限。
2. スティックを離す、歩行へ切り替える、メニューを開く、別アプリへ移ると加速がリセットされる。再開後は通常の走行から始まる。
3. 上部の空腹度（0が満腹・100が空腹）を押して持ち物を開く。買った食品を食べると表示値と個数が更新される。メニュー中は空腹が進まない。
4. 食品がない場合は「自宅の軽食へ案内」を選び、帰宅して無料の軽食を食べる。所持金0円でも空腹度が0に戻る。眠って朝を迎えた場合も朝食で0になる。
5. 設定から保存してページを再読み込みし、空腹度と持ち物が続いていることを確認する。縦向き・横向きで空腹度、倍率、地図などのメニュー、矢印、走るボタンが読めることも確認する。

クラウドでは320×568・390×844・568×320・844×390の表示と操作を検査している。これらの画面エミュレーションと、手元のスマホでの操作感・性能の結果は区別する。仕様と検証結果は [連続走行と空腹度](20261018_sprint_hunger.md) を参照。

## 遊びの確認

- 左スティックで歩き、画面をドラッグして視点を動かす。設定・持ち物・地図と、近くの人や店の操作を縦横で使う。
- 住人と話す → おつかいを受ける → 店へ届ける → 報酬でだんごを買う → 持ち物から食べる。
- 音をオン・オフにし、自宅へ入る・座る・眠る・外へ戻る。公園の収集と桜まつりも確認する。
- 保存後に再読み込みして所持金・持ち物・日付・現在地が戻ることを確かめる。保存は同じブラウザ・同じサイト内だけで、他端末とは同期しない。

## 道案内と夜の確認

1. 地図で目的地を選ぶ。画面をなぞってカメラを回し、矢印が次の曲がり角に合わせて左右・後ろへ向くことを確認する。到着したら、表示された操作ボタンが使える距離まで近づく。
2. 設定の「目的地の矢印をオフにする」を押す。矢印が消えても地図・文字の案内で歩けること、再読み込みしてもオフを保つことを確認し、必要なら再びオンにする。
3. 夜の案内で「自宅への帰り道を案内」を選び、家の入口から入る。「朝まで休む」から次の朝8時へ進み、「街へ出る」で歩きを再開する。持ち物・所持金・途中の依頼を保つことを確認する。
4. 夜の散歩を選ぶ場合も、後から「暮らし」の「今日」から自宅へ案内できることを確認する。同じ夜の案内は日付をまたいでも繰り返さず、午前0〜7時台に眠った場合はその日の8時へ進む。

## 追加した遊びの確認

- **手帳の操作**：「暮らし」の「今日・人の物語・散歩・絵はがき・日々の記録」を縦画面・横画面で開く。見出し、選択肢、閉じるボタンまでスクロールでき、閉じたあと移動スティックが使えることを確認する。
- **住人の3つの短編**：桜・海・駅の物語を住人から聞く。2つの選択肢を読み、ひとつを選んで現地へ歩き、提示された行動を行う。「人の物語」から最初の本人に会いに行き、見つけたことを伝える。住人が休む夜22時〜朝6時は進行が消えず、朝に続きを話せることも確認する。
- **3つの散歩テーマ**：「桜と街の、ひと休み」「海と空を、つなぐ道」「帰りたくなる街」から選ぶ。各3地点を好きな順に訪れ、途中でテーマを変えたり自由な散歩に戻したりしても記録が残ることを確認する。夜や特定の天気を待つ必要はない。
- **6か所の発見**：公園・喫茶店・駅・海辺・展望台・自宅で「今いる場所を見つめる」から「景色を手帳に残す」を選ぶ。初回の日時・天気が絵はがきに残り、再訪しても上書きされないことを確認する。再訪時の「いま、この場所で」の文章は、その時刻や天候に応じた内容になる。
- **お気に入りと再訪**：絵はがきの「大切な場所にする」で1か所を選び、その場所への案内を使う。再読み込み後もお気に入りを保ち、別の場所に変えたり外したりしても元の絵はがきが消えないことを確認する。
- **景色の鑑賞と復帰**：公園・海辺・展望台の案内の絵に近づき、「手帳を閉じて、景色を眺める」を選ぶ。スワイプで見渡し、「街歩きに戻る」で通常の視点と移動操作へ戻れることを確認する。キーボードがある場合はEscでも戻れる。
- **保存と続き**：短編の途中、散歩の途中、お気に入りを選んだ状態で保存して再読み込みする。選んだ答え、行った現地の行動、初回の発見を保ち、続きへの案内が使えることを確認する。以前の保存形式3から再開する場合も、所持金・持ち物・既存の依頼や思い出が残ることを確認する。

気になる挙動は、機種・OS・ブラウザ・画面の向き・ビルド名と、直前に選んだ場所や操作を添えて記録する。クラウドでの画面サイズ・タッチイベントの検証と、実機の操作感・FPS・自動調整の判定は分ける。実機で未確認の項目は未確認のまま残し、測定済みとは扱わない。
