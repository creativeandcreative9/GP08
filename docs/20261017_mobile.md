# スマホ実機での確認

[GP08をブラウザで開く](https://creativeandcreative9.github.io/GP08/)。r47の公開用ビルドindex-BBjCcNE9.jsをGitHub Pagesへ配置し、公開処理は成功済み。スマホのSafari／Chromeから直接開ける。私有モデル・参考画像やPCでのZIP配信は不要。公開URLからHTML・JS・CSS・ハッシュ一覧を直接取得して検証済みビルドとの一致を確認した。端末での描画・操作・性能は以下の手順で確認する。

別の配信先を使う場合は公開用dist/またはZIPの展開内容を通常の静的サイトへ置く。ファイルを直接開く方法には対応しない。PCを利用できる場合は展開フォルダーで `python3 -m http.server 8080 --bind 0.0.0.0` を実行し、同じWi-FiのスマホからそのPCのLANアドレスの8080番を開く。配信するのは展開した公開ファイルだけとし、リポジトリや私有アセットの親フォルダーを指定しない。

## 動作の計測

1. スマホの通常のSafari／Chromeで開き、設定の「画質：自動調整で再開」を選ぶ。タッチ端末は軽量画質から始まる。
2. 駅前から商店街、公園へ1分ほど歩く。読み込み直後の準備を終え、縦画面・横画面で操作できることを確かめる。
3. 設定の「動作を30秒測る」を押し、準備表示のあと、同じ道をいつもどおり歩く。メニューや別アプリを開いている間は計測が止まる。
4. 完了メッセージが出たら、設定の「動作の確認」で平均FPS・中央値・遅い側のフレーム時間を確認し、「結果をコピー」を押す。コピーできない場合は結果欄を長押ししてコピーする。
5. 機種、OS、ブラウザと、歩いた場所・気になったカクつきを添えて結果を共有する。向きや画質を変えて再計測する場合は、先に結果を控える。再読み込みで計測結果は消える。ゲームのセーブは通常どおり保持される。

現行版はビルド名index-BBjCcNE9.jsで区別する。結果には測定日時・ビルド・ブラウザ・フレーム数と時間・測定前後の画質／描画サイズ／解像度倍率・画面サイズを含む。ゲームの所持金・座標・セーブ内容・アクセス先URLは含めず、自動送信しない。遅いフレームは省かず、平均FPSは全測定時間から求める。これは歩いた範囲の計測であり、全端末・全場面の性能保証にはしない。

## 遊びの確認

- 左スティックで歩き、画面をドラッグして視点を動かす。設定・持ち物・地図と、近くの人や店の操作を縦横で使う。
- 住人と話す → おつかいを受ける → 店へ届ける → 報酬でだんごを買う → 持ち物から食べる。
- 音をオン・オフにし、自宅へ入る・座る・眠る・外へ戻る。公園の収集と桜まつりも確認する。
- 保存後に再読み込みして所持金・持ち物・日付・現在地が戻ることを確かめる。保存は同じブラウザ・同じサイト内だけで、他端末とは同期しない。

クラウドのタッチ・画面サイズのエミュレーションは成功しているが、実機の操作感・FPS・自動調整は実機の結果を受けて判定する。PC GPUの検証とは分ける。
