# 見た目の評価基準（参考画像との比較）

参考画像（ユーザー提供の5枚。日本の春の街を目線の高さで描いた、アニメ調の3D映像のスクリーンショット）と同等の見た目を目標にする。
この文書は、その差を **数値で測り、毎回同じ方法で採点する** ための基準。

- 参考画像そのものはこの公開リポジトリに置かない（第三者の映像のため）。手元で指標を比べたいときは、非公開の `../gp08-assets/refs/ref1.png` 〜 `ref5.png` に置くと `npm run eval` が類似度も出す。
- 採点は「参考画像＝100点」として行う。

**共通する特徴**
- 光：晴れた午後の太陽。建物・電柱・木の影がくっきり落ち、影の縁は柔らかい。軒下や物の足元が暗い（AO）。日向は暖色、日陰は青みがかる。窓に光の筋、明部がにじむ（ブルーム）
- 色：彩度を抑えたパステル調（桜色・空色・クリーム・木の茶）。白飛び・黒つぶれがなく階調がなめらか。遠景は霞む
- 質感：木目、タイル、石畳、瓦、ガラスの透過と映り込み。単色のベタ塗り面がほとんどない
- 密度：目線の高さで、手前から奥まで小物（看板・鉢・自転車・ポール・標識・電線）が途切れずに続く
- カメラ：人の目線（約1.5 m）。手前・中景・遠景の重なりで奥行きを出し、通りの消失点へ視線を導く

## 3. 採点ルーブリック（10項目 × 10点 = 100点）

各項目に4つのチェックポイントがあり、それぞれ **0（無い）／1（ある：簡素）／2（参考画像並み）** で付ける。
項目点 = チェックポイント合計(0〜8) ÷ 8 × 10。各カットを採点し、5カットの平均を総合点とする。
採点者は撮影画像を参考画像（無い場合は上の言語化）と見比べ、根拠を一言添える。

| # | 項目 | チェックポイント |
|---|---|---|
| 1 | 光と影 | a 建物・電柱・木が落とす投影影 / b 柔らかい影の縁と接地影（軒下・足元のAO） / c 日向の暖色と日陰の寒色の対比 / d 光の演出（明部のブルーム、光の筋、ガラスのハイライト） |
| 2 | 色彩と空気感 | a 彩度を抑えたまとまった春の配色 / b トーンマッピングでなめらかな階調 / c 遠景の霞（空気遠近法） / d 空のグラデーションと描き込まれた雲・遠くの山並み |
| 3 | 素材感 | a 木・石・タイル・レンガの質感の描き分け / b 屋根材（瓦の段）・外壁材 / c ガラスの透過（中が見える）と映り込み / d 色むら・目地・汚れでベタ塗り面がない |
| 4 | 建物の作り込み | a 店先の奥行き（サッシ枠・方立・段差・凹凸） / b ガラス越しの店内（棚・商品・照明） / c 庇・オーニング・テラス・デッキ / d 住宅の細部（窓枠・雨戸・室外機・ベランダ・雨樋・門扉） |
| 5 | 看板・文字 | a 主看板（店名・ロゴ・帯） / b 袖看板・のぼり・暖簾・A型黒板・ポスター / c 道路標識・住居表示などの街の文字 / d 文字が鮮明で、書体・色が店の性格に合う |
| 6 | 道路と歩道 | a 縁石の段差と歩道舗装の目地・模様 / b 黄色の点字ブロック / c 路面標示（止まれ・停止線・横断歩道・外側線） / d 路面の細部（マンホール・側溝の蓋・花びらの吹き溜まり） |
| 7 | ストリートファニチャー | a 電柱（黄黒カバー・腕金・変圧器）と電線の束 / b 丸ポスト・車止め・ガードパイプ・カーブミラー・標識 / c 自販機・自転車・ベンチ・ごみ箱・鉢植え / d 歩道の端に生活の小物が途切れず続く密度 |
| 8 | 植生と桜 | a 桜の幹と枝ぶり（枝分かれが見える） / b 花の量感（房状の重なり・明暗・色の揺らぎ） / c 舞う花びらと地面の花びら / d 生け垣・鉢植え・街路樹など緑の多様さ |
| 9 | 生活感 | a 歩行者（複数・服装の違い） / b 車（停車・走行） / c 店員・駅員・動物などシーンに合う人物 / d 動き（花びら・人・車・のぼりの揺れ） |
| 10 | カメラと構図 | a 目線の高さと人のスケール感 / b 手前・中景・遠景の重なり / c 寸法の自然さ（ドア約2 m・歩道幅・電柱の太さ） / d 消失点や主役への視線誘導 |

室内（ref3）は読み替える：6＝床（タイル・点字ブロック・案内表示）、7＝改札機・券売機・ごみ箱・ベンチ、2d＝窓の外の景色と照明。

### 自動指標（`npm run eval` が出す。傾向の追跡用）

| 指標 | 意味 | 参考画像の傾向 |
|---|---|---|
| edges | 輪郭画素の割合（描き込みの量） | 高い |
| detail | ラプラシアン平均（細かい質感） | 高い |
| blockStd | 8×8 ブロック内の明暗差（局所コントラスト） | 高い |
| entropy | 色のエントロピー（ベタ塗りだと低い） | 高い（多くの色がなめらかに分布） |
| shade | 周囲より明確に暗い画素の割合（影・AO・隙間） | 中程度（影がある） |
| saturation / colorfulness | 彩度・色の豊かさ | 中程度（パステル調） |
| pink | 桜色の割合 | 桜のカットで高い |

参考画像が `../gp08-assets/refs/` にあれば、各指標の近さから類似度（0〜100）も出る。無い場合は、ルーブリックの点数を正とし、指標は回ごとの変化を見るのに使う。
