# GP08

鎌倉風の日本の街（桜・海・山）でのんびり暮らす、ブラウザ向け 3D ライフシミュレーションゲーム。Babylon.js で作っています。

現在は「段階1」（手描き地図から組み立てた町を、吹雪が歩ける）です。町は完全に手続き生成で、画像ファイルを使わず、シェーダーと動的テクスチャで質感を出しています。

- 町：駅・駅前公園・商店街・住宅街・大学と高校・海と砂浜・展望台のある山。1,300 棟以上の建物、路地、店の内部、歩いて入れる駅の改札
- 見た目：太陽の影、接地影、トーンマッピングと色調整、桜（枝・花・舞う花びら）、電柱と電線、街の小物、木目・レンガ・瓦・ガラスの質感
- 操作：W A S D で歩く、Shift で走る、マウスでカメラ
- 画質：既定は GPU があれば高画質。`?gfx=low` で影と後処理を切る（遅い環境向け）
- 確認用の視点：`?view=overview`（俯瞰）、`street`、`platform`、`alley`、`summit`、`ref1`〜`ref5`（参考画像と比べるための目線の高さの5カット）。キャラクターなしは `?model=none`

## セットアップ

```bash
npm ci
# 非公開アセット用リポジトリ creativeandcreative9/GP08-assets をこのリポジトリの隣にクローン
#   ../gp08-assets/ に zip が入っている状態にして、展開する
npm run assets:extract     # -> private-assets/seisen/
npm run dev                # http://127.0.0.1:5178/
npm test                   # Playwright のテスト（町の生成・歩行・道路・桜・住宅など）
npm run shot               # screenshots/shot.png を保存（--query "?view=ref1" などが使える）
npm run eval -- --tag <日付>_<名前>   # 比較カット5枚と画像指標（screenshots/eval/ に保存。コミットしない）
```

見た目の評価の基準と採点は `docs/20261016_visual_eval.md` にあります。環境変数 `GP08_PORT` で開発サーバーのポートを変えられます。
