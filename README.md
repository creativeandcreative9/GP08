# GP08

鎌倉風の日本の街（桜・海・山）でのんびり暮らす、ブラウザ向け 3D ライフシミュレーションゲーム。Babylon.js で作っています。

街の構築と歩行を土台に、時間・天候、室内、会話と親しさ、買い物、収集、桜まつり、セーブを実装しています。10月18日の開発版では、画面上の道案内、夜の過ごし方、選べる寄り道、7つの思い出を残す手帳とUIを改善しています。町は完全に手続き生成で、画像ファイルを使わず、シェーダーと動的テクスチャで質感を出しています。

- 町：駅・駅前公園・商店街・住宅街・大学と高校・海と砂浜・展望台のある山。1,300 棟以上の建物、路地、店の内部、歩いて入れる駅の改札
- 見た目：太陽の影、接地影、トーンマッピングと色調整、桜（枝・花・舞う花びら）、電柱と電線、街の小物、木目・レンガ・瓦・ガラスの質感
- 操作：W A S D / 矢印 / タッチスティックで歩く、Shift / 走るボタンで走る、マウスやスワイプでカメラ
- 暮らし：E で住人と会話・店先で買い物、I で飲食、J で依頼帳。住人のおつかいを届けると400円の報酬。所持金・持ち物・依頼・現在地をこのブラウザに自動保存
- 街歩き：M で地図。画面の矢印がカメラに合わせて次の曲がり角を示し、到着後の操作も案内。選んだ行き先と矢印のオン／オフを保存。配達中は地図に届け先も表示
- ひと休み：公園中央の道沿いの空いたベンチに E で座る。座ったまま I でおやつを楽しみ、E / Esc で立ち上がる
- 暮らしの一日：昼夕夜と晴れ・曇り・雨。夜は帰宅と散歩の継続を選べる。自宅で一日を振り返って眠ると、次の朝8時へ。毎日のあいさつと配達で住人の応答も変わる
- 思い出：暮らしの手帳で「人に会う・景色を探す・家で休む」から寄り道を選び、実際に過ごした7つの出来事を日時付きのアルバムで読み返す
- 収集と行事：公園の花びらと海の貝がらを拾う。1・4・7…日目の9〜21時、公園の桜まつりで記念品を受け取る
- 設定：音量、BGM・環境音、画質、3つのセーブ記録。音は操作してオンにする
- 画質：タッチ端末とソフトウェア描画は軽量、その他は高画質から性能に合わせて自動調整。`?gfx=low` で影と後処理を切る（遅い環境向け）
- 確認用の視点：`?view=overview`（俯瞰）、`street`、`platform`、`alley`、`summit`、`ref1`〜`ref5`（参考画像と比べるための目線の高さの5カット）。キャラクターなしは `?model=none`

10月18日の改善後は、全150ケースの最終成功を確認した。初回一括実行は149成功・旧移行テストの期待値差1失敗（13.5分、スキップ0）。厳密比較を維持して新しい2フィールドの初期値を期待値へ追加し、移行・時計・思い出の関連22件がすべて成功（1.4秒）した。アプリ本体は変更していない。型チェックとビルド、公開158ファイルだけの静的配信検査も成功。昼・夜・雨・スマホ縦横・計測の6画像を実際に確認し、ページエラーと私有アセット要求は0件。音・保存・実タッチイベントによる移動を確認した。 昼の固定5視点は美術評価90.00点を維持。スマホ実機の性能は未確定。

道案内・操作・選択・人とのつながり・記憶を含む固定10軸40項目の設計品質評価は **61.00 → 92.75点**。目標の総合90点超・全軸8点以上を達成しました。[研究と設計の根拠](docs/20261018_play_research.md) と [10軸40項目の体験評価](docs/20261018_experience.md) に、評価方法と確認結果を記録します。以前の[画像評価90点](docs/20261016_visual_eval.md)とは別の指標で、人間が感動した割合を測るものではありません。全体計画の状態は [受け入れ確認](docs/20261016_completion.md) を参照してください。

## はじめての街歩き

1. 駅前から歩き、近くの住人に **E** であいさつする。
2. **M** または画面の **地図** で和菓子屋を選び、画面の矢印が示す次の曲がり角へ歩く。**お店案内** からも選べる。
3. 店先で **E** を押し、三色だんごを180円で買う。初期の所持金は1,200円。
4. **I** または **持ち物** を開き、だんごを食べる。3つの目標を達成すると、お祝いに500円を受け取れる。

コンビニではおにぎり、カフェでは持ち帰りコーヒーも買えます。会話・メニューは **Esc** または閉じるボタンで閉じます。メニューを開いている間はキャラクターの移動を止めます。

## 住人のおつかい

住人に話しかけて **おつかいを引き受ける** を選ぶと、注文票やお知らせを預かります。配達先は和菓子屋・コンビニ・カフェのいずれか。案内を目安に店先まで歩き、**E** でお店を開いて **預かり物を渡す** と400円を受け取れます。立て替えはないので、所持金0円からでも始められます。

**J** または **依頼帳** で、依頼主・預かり物・行き先・報酬と最近の完了履歴を確認できます。引き受けられるのは1件ずつ、各住人の依頼は1回までです。取りやめてもお金は減らず、同じ住人から再び引き受けられます。依頼の途中でページを閉じても、再開後にそのまま届けられます。住人には名前がつき、届けた後はお礼を言ってくれます。

**M** または **地図** を開くと、北が上の概略図に現在地と目的地の番号を表示します。壁・海・大きな段差を避ける経路を計算できた場合は、地図に緑の線、プレイ画面には次の曲がり角へ向く矢印と残りの道のりを表示します。カメラを回すと矢印の向きも変わり、到着時には次の操作を案内します。経路が見つからないときは矢印を出さず、文字の方角案内を残します。道へ出ると再計算します。

配達先は茶色、案内中の場所は緑の輪で表示。寄り道を選んでも依頼は残り、依頼帳の **配達先へ案内** で戻せます。選んだ散歩先は保存され、再読み込み後も続きから案内します。慣れたら **設定 → 目的地の矢印をオフにする** で隠せます。この設定も保存され、地図と文字の案内は引き続き使えます。自動歩行はしないので、道や踏切を通って歩いてください。

進行は5秒ごと、購入・会話・飲食・依頼の変更時、ページを離れる際に自動保存します。**保存** ボタンでも保存できます。同じブラウザ・同じサイトのアドレスで開くと前回の現在地から再開します。以前のセーブは所持金・持ち物・進行・現在地を保って自動移行します。ブラウザのサイトデータを削除するとセーブも消えます。サーバーや別端末への同期はありません。保存できない環境では画面に表示します。

## ベンチでひと休み

公園中央の道沿いにある10脚のベンチでは、先客のいないベンチの正面に近づくと **E** で座れます。休憩は無料です。マウスで景色を眺めたり、**I** で持ち物のおやつを食べたり、**M** で地図・**J** で依頼帳を開けます。

メニューを **Esc** で閉じても休憩は続きます。休憩画面で **E**、**Esc**、または **立ち上がる** ボタンを押すと、ベンチ前へ戻って歩けます。休憩中に保存・終了した場合も、次回はベンチ前から立った状態で再開します。飲食や依頼の進み具合はそのまま保存されます。

非公開モデルがなくてもオリジナルの公開用キャラクターで遊べます。開発時は私有パックがあれば吹雪を使い、`?model=public` で公開用キャラクターに切り替えられます。公開ビルドの既定は公開用キャラクターです。`?model=none` と `?view=...` は街の確認用で、会話・買い物の画面を出さず、セーブも変更しません。

クラウド環境では `source /workspace/gp08-cloud-setup/env.sh` で導入済みChromiumの設定を読み込めます。`npm run shot` は独自にサーバーを起動するため、開発サーバーを止めるか `GP08_PORT=5180 npm run shot` のように別ポートを指定します。


## 一日を過ごす

画面の時計はプレイ中に進み、メニューと非表示のタブでは止まります。住人は朝の用事、昼休み、散歩、帰り道へと活動を変え、夜22時から朝6時は家で休みます。毎日話しかけると親しさが増え、顔なじみになると会話が増えます。

店先の買い物画面から **お店の中に入る** を選べます。店内のカウンターで買い物し、椅子で休み、玄関のマット付近で **E** を押すと同じ店先へ出ます。室内で保存しても、次回は屋外の安全な位置から再開します。

日が暮れると、画面に **自宅への帰り道を案内** と **夜の散歩を続ける** が出ます。歩きを止める強制メニューではなく、好きな過ごし方を選べます。夜の散歩を選んだあとも **暮らし → 自宅へ案内してもらう** から帰れます。

自宅の入口で **E** または操作ボタンを押すと家へ入れます。家の案内カードの **朝まで休む**、または左奥の布団を選ぶと、一日の思い出と睡眠後の日付を確認できます。**眠って翌朝を迎える** で次の朝8時へ進み、おつかい・持ち物・所持金は続きます。午前0〜7時台なら、その日の朝8時へ進みます。目覚めたら **街へ出る** で散歩を再開できます。

**暮らし** の先頭では、公園で人に会う、海辺で発見を探す、自宅で休む、の3つから寄り道を選べます。夜の公園は夜の散歩、海辺の思い出を得たあとは展望台への案内になります。選んだ行き先を自動のおすすめが上書きすることはありません。

その下のアルバムには、初めてのあいさつ、おつかい、公園のベンチでのおやつ、海辺の貝がら、展望台、自宅で迎える朝、桜まつりの7つの思い出を残せます。実際に行った出来事だけを日時付きで記録し、未体験のカードにはヒントを表示します。順番や期限は自由です。住人の返事も、顔なじみになったことや届けた品物、時間と天候などに応じて変わります。

収集品と住人との親しさも同じ手帳で確認できます。公園で拾う花びらは、開催中の桜まつりのピンクの受付へ。花びら3枚と、その日3人へのあいさつで600円と緑茶を1回受け取れます。花びらは翌日また拾えます。海辺では貝がらも集められます。

**設定** には音・音量・画質・セーブ記録1〜3があります。記録の読み込みと最初から始める操作には確認画面が出ます。記録は同じ端末・同じブラウザに保存されます。

## 公開用ビルド

`npm run build` で `dist/` を生成します。静的Webサーバーでこのディレクトリを配信すれば、非公開アセットなしで遊べます。環境音とBGMもコードで生成します。配信前に、`dist/` に私有モデルやテクスチャをコピーしていないことを確認してください。10月18日の公開用ビルド `index-BHXfbBUw.js` は静的配信で検証済みです。公開URLへの反映結果は受け入れ確認に記録します。

全体計画の受け入れ状況は [docs/20261016_completion.md](docs/20261016_completion.md) で確認できます。

`npm run build` の後に `node tools/verify-release.mjs` を実行すると、公開ファイルだけの静的配信で昼・夜・雨・音・保存・タッチ操作を検証します。クラウドでは先に上記のChromium設定を読み込みます。依存ライブラリの表示は配布物内の `THIRD_PARTY_NOTICES.txt` に含めています。

## 重要なルール（モデルデータの扱い）

- MMD モデルファイルは **非商用利用のライセンス** で提供されています。
- **再配布禁止**。この公開リポジトリには **絶対にコミットしない** でください（`private-assets/`、`*.pmx` などは `.gitignore` 済み）。
- モデルは非公開の `GP08-assets` リポジトリでのみ管理します。ビルド成果物 `dist/` にも含めません（開発・プレビューサーバーが `/private/` で配信するだけです）。
- モデルが写ったスクリーンショットもコミットしないでください。

## 性能を確認する

スマホでは設定の「動作を30秒測る」から計測し、完了後に「結果をコピー」を使えます。平均FPS・フレーム時間と測定前後の画質・描画サイズを記録します。[実機確認の手順](docs/20261017_mobile.md) を参照してください。

GPU搭載PCで `GP08_PORT=5181 node tools/benchmark.mjs --headed --frames 180 --query '?model=public'` を実行すると、画質の自動調整を待ってからフレーム時間・GPU名・描画数を `screenshots/performance.json` に保存します。`--warmup` で計測前のフレーム数を指定できます。GPUのないクラウドの診断だけ `--software` を付けます。その結果でスマホやPC実機の合格は判断しません。

公開用ビルドは `npm run build` で `dist/` に生成します。既定の主人公はオリジナルで、非公開モデルの配信を必要としません。配信するファイルはこのディレクトリだけにし、`private-assets/` や比較画像を含めないでください。
